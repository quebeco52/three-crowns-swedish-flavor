# Triggers for the Novgorod protectorate (swe_novgorod).

# Location scope. The Novgorod lands that go to the protectorate (swe_novgorod.1): the eastern
# Novgorod area with the city itself, Staraya Russa and the Luga country. Kexholm and Ingria
# (swe_kexholm_ingria_trigger) stay with Sweden, as they did at Stolbovo in 1617.

	OR = {
		area = area:east_novgorod_area
		province_definition = province_definition:knyazhaya_province
		province_definition = province_definition:luzhkaya_province
	}
}
